# prototype-user-test

Скилл для агента (Claude Code, Codex, Cursor и др.): кликабельный прототип для юзтеста → события каждого действия в Google-таблицу → тепловая карта тапов → отчёт с выводами по вариантам.

## Установка

```bash
# Claude Code
git clone <url этого репозитория> ~/.claude/skills/prototype-user-test

# другие агенты
git clone <url этого репозитория> ~/.agents/skills/prototype-user-test
```

Агент без поддержки скиллов: дай ему путь к `SKILL.md` и попроси следовать.

## Как пользоваться

Пиши агенту обычным языком: «собери прототип для юзтеста…», «дай скрипт для таблицы», «проверь, что события доходят», «сделай выводы и тепловую карту». В Claude Code можно вызвать явно: `/prototype-user-test`.

Ручные шаги за тобой: Google-таблица со скриптом (с **личного** аккаунта), тесты в панели (своя ссылка с `?r=` на каждый), выгрузка CSV панели. Остальное делает агент.

## Файлы

| Файл | Что это |
| --- | --- |
| `SKILL.md` | Инструкция для агента: типы тестов, события, запуск, анализ, частые ошибки |
| `testlog-template.ts` | Логгер событий и тапов для прототипа |
| `apps-script-logger.gs` | Приёмник событий для Google-таблицы (Apps Script) |
| `heatmap-viewer.html` | Вьюер тепловой карты: CSV таблицы + скриншоты экранов |
| `capture-screens.mjs` | Скриншоты экранов прототипа для вьюера (Node 22+, Chrome) |
